A tiny Node program with one job: write a single one-liner about AI coding agents to /output/entry.txt for make.fun's AI comedy judge. The joke is a rule of three on the word "take" — a coding agent needs no coffee breaks and no sick days, and, as every developer who works beside one knows, it doesn't take the requirements seriously either. Standard library only, no network, deterministic: every run writes exactly the same 112 characters.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
